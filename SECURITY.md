# Security Policy

## Supported versions

NT is pre-1.0 and under active development. Security fixes are applied to the
latest published release of each package (`@age.nt/engine`, `@age.nt/nt`) and
the VS Code extension.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Instead, report privately via GitHub's
[private vulnerability reporting](https://github.com/kartikmehta8/nt/security/advisories/new)
or email **kartikmehta202@gmail.com**.

Include, where possible:

- a description of the issue and its impact,
- a minimal `.nt` file or steps to reproduce, and
- the affected package and version.

You can expect an initial acknowledgement within a few days. Once a fix is
released, we're happy to credit reporters who wish to be named.
