Getting NT ready takes four small steps: install it, set your AI key, check it
works, and create a project.

## Step 1: Install the CLI

NT is a command called `nt`. Install it with your package manager:

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>

<Tab value="npm">

```bash
npm install -g @age.nt/nt
```

</Tab>

<Tab value="pnpm">

```bash
pnpm add -g @age.nt/nt
```

</Tab>

<Tab value="yarn">

```bash
yarn global add @age.nt/nt
```

</Tab>

<Tab value="bun">

```bash
bun add -g @age.nt/nt
```

</Tab>

</Tabs>

The `-g` means "global", so you can use the `nt` command from any folder.

<Callout type="warn" title="You need Node 22.18 or newer">
  NT runs on Node.js. Check your version with `node --version`. If it is older than 22.18, update
  Node first.
</Callout>

## Step 2: Set your AI key

NT talks to a real AI model, so it needs a key. If you are using Anthropic
(Claude), set it like this:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

You only need this when you actually run an agent. Checking and inspecting your
files works without a key.

## Step 3: Check it works

```bash
nt --help
```

If you see the list of commands, you are ready.

## Step 4: Create a project

`nt setup` writes a small working project into the current folder, so you never
start from a blank file:

```bash
mkdir my-agent && cd my-agent
nt setup
```

```text
Setting up an NT project in /Users/you/my-agent
  template: minimal
  + age.nt
  + config.nt

✓ 2 file(s) OK

Next steps
  1. export ANTHROPIC_API_KEY=sk-ant-...
  2. nt run age -m "bought the first iPhone at 22"
```

`age.nt` holds the agent and `config.nt` holds your settings and AI provider.
Run that last line and you have a working agent.

<Callout title="Want to see everything at once?">
  `nt setup --template full` writes a bigger starter with a tool, a skill, a sandbox, a helper
  agent, and a workflow — one of each, in its own file. See [CLI
  commands](/docs/reference/cli#starting-a-project).
</Callout>
